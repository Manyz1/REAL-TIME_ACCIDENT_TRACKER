# Icon Files — Place your PNG images here

All icons should be PNG format with transparent background.
Recommended size: 24×24 px or 32×32 px.

| Filename          | Used for                                      |
|-------------------|-----------------------------------------------|
| app.png           | Browser tab icon (32×32 recommended)          |
| window.png        | "Live Window" source option                   |
| video.png         | "Video File" source option                    |
| display.png       | "Live Display" output option                  |
| save.png          | "Save as Video" output option                 |
| idle.png          | Status: system is idle / not started          |
| normal.png        | Status: no incident detected                  |
| suspected.png     | Status: possible crash, verifying with CLIP   |
| confirmed.png     | Status: accident confirmed                    |
| done.png          | Status: video file fully processed            |

If a file is missing, its slot in the UI will be empty — no crash occurs.
